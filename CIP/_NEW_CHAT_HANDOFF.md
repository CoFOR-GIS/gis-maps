## What This Project Is

The City of Fair Oaks Ranch (CFOR) is building a public-facing interactive map of their Capital Improvement Projects (CIP). Project data lives in **ClearGov** (a municipal transparency platform). The map is hosted on **GitHub Pages** as a single static HTML file, and pulls data from **ArcGIS Online** (AGOL), which in turn is populated by a **Python sync script** that fetches from ClearGov's API.

**Read first:** [`OVERVIEW.md`](OVERVIEW.md) for the executive summary, [`ARCHITECTURE.md`](ARCHITECTURE.md) for system design.

## Critical Context

### The User

**Ernie Martz** — GIS Administrator at City of Fair Oaks Ranch. Manages AGOL org `fairoaksranch.maps.arcgis.com`. Reports to City Engineer Lee Muniz. Has established CFOR GIS standards, runs scripts via ArcGIS Pro Python Command Prompt, deploys to GitHub Pages at `cofor-gis.github.io/gis-maps/`.

### Critical Standards (Always Follow)

These are non-negotiable for any code in this project. Full list in [`CFOR_STANDARDS.md`](CFOR_STANDARDS.md), but the load-bearing ones:

1. **Naming:** Services follow `CoFOR[Dept]_[Theme]_[Component]` PascalCase. PW = Public Works.
2. **Spatial Reference:** WKID 2278 (NAD83 TX South Central) for storage, WGS84 for ClearGov source data, Web Mercator for display.
3. **No Oxford commas** anywhere user-facing.
4. **Compound words:** stormwater, wastewater (not "storm water").
5. **REST queries:** Always POST with `URLSearchParams`, paginate at 1000.
6. **Public app auth:** Blanket-reject `esriId.getCredential` in any public-facing HTML.
7. **AMD load order:** UMD libraries (Chart.js, jsPDF, Shepherd.js) MUST load BEFORE the ArcGIS SDK.
8. **`or {}` not `.get(key, {})`** — always handle None values explicitly when navigating dicts in Python.
9. **`_args` fallback** for ArcPy scripts to handle exec mode in Pro Python window.
10. **Public view pattern** — never share authoritative services directly; always create a separate read-only view.

### Critical Workarounds Already in Place

These were resolved earlier; don't re-introduce the bugs:

- **Python sync uses pure REST**, not `arcgis` package. The `arcgis` package triggers a numpy/pandas binary incompatibility in ArcGIS Pro's Python env. Stick to `requests` + `arcpy`.
- **Web map uses imperative `new Map()` + `new MapView()`**, not the `<arcgis-map>` web component. The web component requires an extra script tag.
- **Geometry extraction handles GeoJSON Feature wrappers**. ClearGov changed their structure mid-project — markers are flat `{lat,lng}`, polygons are GeoJSON Features with nested `geometry.type`/`geometry.coordinates`.
- **Multi-geometry projects produce multiple features**. A project with 2 markers + 1 polygon → 3 features in AGOL.
- **Public view created via AGOL UI, not REST**. The REST script (`create_public_view.py`) fails on `addToDefinition` for view layers. The UI workflow is reliable.
